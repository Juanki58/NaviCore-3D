# Contributing to NaviCore-3D

Thanks for your interest in improving NaviCore-3D.

## License and CLA (required)

NaviCore-3D is dual-licensed:

- **Open path:** [GPL-3.0-or-later](LICENSE)
- **Commercial path:** see [COMMERCIAL.md](COMMERCIAL.md)

To keep dual licensing possible, **every contributor must accept the Individual CLA** before a pull request is merged:

1. Read [CLA.md](CLA.md) (draft pending legal review).
2. In your PR description, include the acceptance block from `CLA.md`.
3. **No CLA acceptance → no merge.**

If you contribute on behalf of a company, contact the project owner for an Entity CLA (do not use the Individual CLA alone).

## How to contribute

1. Open an issue describing the change (bug, feature, docs) when the scope is non-trivial.
2. Fork and create a branch from `main`.
3. Keep changes focused; match existing code style (C++17, zero-heap in the navigation tick path, honesty in docs).
4. Add or update tests when behavior changes.
5. Open a PR with:
   - what changed and why;
   - how you tested it;
   - the CLA acceptance statement.

## Development pointers

See [DEVELOPMENT.md](DEVELOPMENT.md) and the README quick-start for build, replay, and regression commands.

## Conduct expectations

- Be respectful and technical.
- Do not overclaim validation, certification, or field results in docs or PR text.
- Do not commit secrets, credentials, or large binary dumps without prior agreement.
